# Ray Tracing in One Weekend — Rust Implementation

This branch contains the final Rust implementation for *Ray Tracing in One Weekend* — Book 1 (Version 4.0.2, 2025-04-25).
The program reproduces the book’s examples and outputs `.ppm` images generated by the renderer.

---

## Requirements

* Rust toolchain (install from [rustup.rs](https://rustup.rs))
* Rayon crate (declared in `Cargo.toml`) for parallel rendering

---

## Build

Compile the project in release mode:

```bash
cargo build --release
```

---

## Usage

Build and run the renderer, redirect output to a `.ppm` file:

```bash
cargo run --release > output_image.ppm
```

Example:

```bash
cargo run --release > results/book1_final.ppm
```

Notes:

* Output is a plain PPM file (view with an image viewer or convert via ImageMagick).

---

## Performance Benchmark (example)

Parallelization uses Rayon and `Arc` for thread-safe shared materials. Benchmark recorded on a machine with **8 logical cores** using:

* Aspect ratio: 16.0 / 9.0
* Image width: 1920
* Samples per pixel: 1000
* Max depth: 50

| Mode       | Real Time   | User Time  | System Time |
| ---------- | ----------- | ---------- | ----------- |
| Sequential | 198m26.032s | 198m9.218s | 0m6.954s    |
| Rayon      | 75m45.106s  | 571m0.343s | 0m59.481s   |

Observed wall-clock speedup: **~2.6×** (real time). Actual results vary by CPU, memory bandwidth, and scene.
