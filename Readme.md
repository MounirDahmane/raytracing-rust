# Ray Tracing in One Weekend — Rust Implementation

This repository contains a Rust implementation of *Ray Tracing in One Weekend* by Peter Shirley, Trevor David Black, and Steve Hollasch (Version 4.0.2, 2025-04-25).  
The program outputs `.ppm` images generated by ray tracing, following the book’s examples.

---

## Requirements

- Rust toolchain ([install from rustup.rs](https://rustup.rs))  
- Rayon crate (included) for parallel rendering

---

## Build

Compile the project in release mode:

```bash
cargo build --release
````

---

## Usage

### Build and run (release mode)

To compile and run the program, redirect the output to save the `.ppm` image:

```bash
cargo run --release > ./directory_if_any/name_of_img.ppm
```

---

## Performance Benchmark with Rayon

I used the Rayon crate to parallelize the rendering process. Below are benchmark results comparing sequential and parallel execution with these parameters:

* Aspect ratio: 16.0 / 9.0
* Image width: 1920
* Samples per pixel: 1000
* Depth: 50

| Mode       | Real Time   | User Time  | System Time |
| ---------- | ----------- | ---------- | ----------- |
| Sequential | 198m26.032s | 198m9.218s | 0m6.954s    |
| Rayon      | 75m45.106s  | 571m0.343s | 0m59.481s   |

Parallel execution cuts real time by over 2.5× compared to sequential.
